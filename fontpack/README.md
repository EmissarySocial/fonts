# ✍️ Fontpack

## A Baseline Set of Beautiful Type for Long-Form Reading

Fontpack is the starting font library for [Emissary](https://emissary.dev) and [Qwertylicious](https://github.com/EmissarySocial/qwertylicious). It exists so that anyone publishing a long article has a broad, genuinely beautiful range of typefaces on hand from the first minute, without hunting down font files, worrying about licensing, or reaching for a third-party CDN that watches their readers.

The bias throughout is toward **reading**, not decoration. Most of what is here is a text face that stays comfortable for a few thousand words: text serifs, slab serifs, and humanist sans. The display and script faces are here to set a title above that text, not to set the text itself.

Every family ships as **TrueType plus WOFF2**. The `.ttf` is the archival original exactly as its foundry published it; the `.woff2` beside it is the one to serve, at roughly a third of the size. Families that publish a variable font keep their `static/` weights too, but only the top-level fonts get a WOFF2 — a variable file already carries every weight.

The pack is curated, not exhaustive. Where two families covered the same ground, one was dropped: a reader choosing a font is better served by fifty distinct options than by eighty with near-duplicates among them.

## The `fonts` Dataset

[theme.hjson](theme.hjson) carries a `fonts` dataset listing every family, shaped as `form.LookupCode` so a font picker can read it directly:

```hjson
{Label:"Literata", Group:"Serif", Value:"Literata", Href:"/.themes/fontpack/resources/Literata/Literata-VariableFont_opsz,wght.woff2"}
```

`Value` is the CSS family name to write into `font-family`. `Href` points at one file per family — the variable upright where the family has one, because that single file already carries every weight, otherwise the regular. Italics and static weights sit beside it in the same folder. `Group` is one of Serif, Slab Serif, Sans Serif, Monospace, Display, or Script.

This mirrors how a template declares a dataset, so the two are now interchangeable in shape. Note that Emissary resolves `options:{provider:"x.y"}` against *template* datasets only, so pointing a form at this list still needs a small template package alongside the theme.

## Installation

Fontpack installs like any other Emissary package, through the **Packages** section of the setup console. Once installed, its families are available to every theme and template on the domain.

## Licensing

Fonts are redistributed here, so their licenses travel with them. Each family keeps its own license file in its own folder — read that file, not this section, when a question actually matters.

- **Most families are [SIL Open Font License 1.1](https://openfontlicense.org)**, shipped as `OFL.txt`.
- **Roboto Slab, Satisfy, and Tinos are Apache 2.0**, shipped as `LICENSE.txt`.
- **Hack is MIT**, over Bitstream Vera and public-domain DejaVu, shipped as `LICENSE.md`.
- **Maragsa is "freeware"** and is the odd one out. Its `info.txt` records a FontSpace link rather than a license text, and "freeware" is not a redistribution grant — it often means personal use only. Nothing here has cleared it for shipping inside a product.
